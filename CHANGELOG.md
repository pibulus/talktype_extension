# TalkType Changelog

All notable changes to the TalkType extension will be documented in this file.

## [1.3.0] - 2025-04-04

### Added
- Context menu integration: Right-click any text field and select "Transcribe with TalkType"
- Visual recording indicator with click-to-stop functionality
- Improved transcription insertion reliability

### Changed
- Removed microphone buttons that were previously added to text inputs
- Simplified user experience with a cleaner, less intrusive approach
- Recording now stops when clicking anywhere on the page
- Updated README.md to reflect new context menu functionality

### Fixed
- Resolved positioning issues with microphone buttons on complex websites
- Fixed visual conflicts with website styles
- Eliminated z-index issues on sites with overlay elements
- Improved compatibility with rich text editors

## [1.2.1] - 2025-03-15

### Added
- Support for more text input types on modern websites
- Improved detection of contentEditable elements
- Better handling of dynamically loaded content

### Fixed
- Resolved issues with microphone button positioning
- Fixed transcription insertion in complex text editors
- Improved reliability on single-page applications

## [1.2.0] - 2025-02-28

### Added
- Dark mode support with automatic theme detection
- Improved visual feedback during recording
- Support for more text input types

### Changed
- Enhanced UI with glass morphism effects
- More responsive audio visualization
- Streamlined recording process

## [1.1.0] - 2025-01-15

### Added
- Support for rich text editors
- Improved transcription accuracy
- Visual indicators for recording state

### Fixed
- Fixed positioning on complex websites
- Resolved issues with transcription insertion

## [1.0.0] - 2025-01-01

### Initial Release
- Voice-to-text functionality for text input fields
- Beautiful glass morphism UI
- Microphone buttons for text fields
- Adaptive light/dark theming
- Gemini API integration for transcription
