TalkType Context Menu Test Page

Instructions:

  1. Make sure the TalkType extension is installed and enabled
  2. Click in any of the input fields below
  3. Right-click inside the field
  4. You should see "Transcribe with TalkType" in the context menu
  5. Click on that option to start recording
  6. Speak into your microphone
  7. Click anywhere to stop recording
  8. Your transcribed text should appear in the field

If the context menu option doesn't appear, try the following:

  1. Make sure you've reloaded the extension after installing it
  2. Try right-clicking in different input fields
  3. Check the browser console for error messages
